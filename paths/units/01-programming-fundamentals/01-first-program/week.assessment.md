# Week 1 self-check

Use your own `me.py` as evidence.

## Predict

Without running it, write the output:

```python
label = "GO"
width = 4
print("+" + "-" * width + "+")
print(label * 2)
```

Then run it and correct your explanation if necessary.

## Explain

Point to:

- one string value;
- one integer value;
- one assignment statement;
- one expression Python evaluates before `print()`;
- one commit that records a working checkpoint.

## Transfer

Add a `version` integer to your program and print a line such as `Version 1`
without typing the digit directly inside the print statement.

You are ready for Week 2 when the program runs and you can explain the change
without reading a generated explanation.
