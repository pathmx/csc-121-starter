# Week 2: Input and decisions

## Destination

Collect user input, convert types intentionally, compare values, and choose
between behaviors with `if`, `elif`, and `else`.

## Evidence

A `you.py` program that asks for a fictional profile, makes at least one useful
decision from the answers, handles a documented invalid range, and prints a
formatted result.

## Week sequence

1. [Lesson: Ask, convert, decide](./01-ask-convert-decide.lesson.md)
2. [Lab: Interactive kiosk](./02-interactive-kiosk.lab.md)
3. [Application: `you.py`](./03-you.project.md)
4. [Self-check](./week.assessment.md)

## Entry

You should be able to run a Python file, assign variables, use basic string and
number operations, and save and submit the intended `.py` file.
