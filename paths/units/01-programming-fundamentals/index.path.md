# Unit 1: Programming fundamentals

Build small interactive Python programs and learn the working habits that make
larger programs possible.

## Unit destination

By the end of Unit 1, you will be able to:

- run and revise a Python program;
- represent information with variables and basic data types;
- collect input and choose behavior with conditionals;
- repeat behavior and update state with loops;
- organize related data with lists;
- decompose behavior into functions;
- save, name, and submit Python files reliably; and
- transfer these capabilities to an unfamiliar small problem.

## Unit map

1. [Week 1: Your first program](./01-first-program/index.path.md) — pilot-ready
2. [Week 2: Input and decisions](./02-input-and-decisions/index.path.md) — pilot-ready
3. **Week 3: Loops and state** — mapped
   - Model a counter, sentinel loop, and small interactive simulation.
   - Lab: trace and repair loops before writing one from a behavior table.
   - Evidence: a program that repeats until a meaningful stop condition.
4. **Week 4: Lists, randomness, and functions** — mapped
   - Store a collection, choose or iterate over items, and extract one focused
     function.
   - Lab: extend a small multi-round game.
   - Evidence: a readable program whose state and behavior are separated.
5. **Week 5: Integration and transfer** — mapped
   - Review by reading, predicting, testing, and repairing programs.
   - Evidence: an integrative application followed by a pencil-and-paper transfer
     exam.

## Unit evidence

The Unit 1 exam should present a new but comparable problem on paper. It should
test problem decomposition, reading and tracing code, values, decisions,
repetition, collections, functions, and debugging without requiring a library,
editor shortcut, or domain students have not seen.
