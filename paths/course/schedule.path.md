# Course schedule

This is the term-neutral 15-week sequence. Your instructor will add actual
dates and announce changes through the official course channel.

| Week | Capability | Main evidence |
| ---: | --- | --- |
| 1 | Run Python; use output, values, and variables | Static profile card (`me.py`) |
| 2 | Collect input and make decisions | Interactive profile card (`you.py`) |
| 3 | Repeat behavior and update state | Small interactive simulation |
| 4 | Use lists, randomness, and functions | Multi-round program |
| 5 | Integrate Unit 1 skills and transfer them | Review project and Unit 1 exam |
| 6 | Model records with dictionaries; read text files | First applied-project checkpoint |
| 7 | Read, transform, and write CSV data | Data-processing checkpoint |
| 8 | Decompose code into modules | Multi-file checkpoint |
| 9 | Install and use one documented package | Domain extension checkpoint |
| 10 | Integrate and transfer Unit 2 skills | Applied project and Unit 2 exam |
| 11 | Propose and scaffold a feasible project | Approved specification and first run |
| 12 | Build the first end-to-end slice | One complete user flow |
| 13 | Reach a working MVP | Demonstrable core experience |
| 14 | Test, revise, and document | Release candidate and README |
| 15 | Present and explain | Demo, repository, and reflection |

See the [course journey](../index.path.md) for unit details.
