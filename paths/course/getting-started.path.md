# How this example course works

Programming is learned by making predictions, writing code, running it,
observing the result, and revising. The example week uses a simple recurring
loop:

1. **Lesson:** see one new capability in a complete example.
2. **Lab:** try it with guidance and immediate feedback.
3. **Assignment:** apply it to a related but independent problem.
4. **Self-check:** predict, explain, and transfer what you learned.

---

## The tools in this example

The example begins in Thonny so a new programmer can focus on Python before
learning a larger development environment. That is a teaching choice, not a
PathMX limitation. An instructor can use another editor, a browser environment,
notebooks, physical computing, data tools, or a different sequence.

PathMX is the course website. It organizes the guided material and lets you
read freely or move through it step by step in Play mode.

---

## Your working loop

When you solve a programming problem:

1. describe the behavior in your own words;
2. choose one small testable step;
3. predict what should happen;
4. type and run the smallest useful code;
5. compare the result with the prediction;
6. revise and save; and
7. explain what the program does now.
