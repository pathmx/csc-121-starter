# Release readiness checklist

## A week is pilot-ready when

- [ ] its capability and entry assumptions are explicit;
- [ ] the lecture contains a runnable worked example;
- [ ] the lab provides a supported attempt and an independent challenge;
- [ ] the project asks for observable evidence of the capability;
- [ ] a self-check, rubric, or answer rationale is available;
- [ ] setup, submission, recovery, and next steps are exact;
- [ ] the starter code was run from a clean copy;
- [ ] PathMX builds and the exact Player route was reviewed.

## The course is release-ready when

- [ ] every intended week is pilot-ready;
- [ ] a subject reviewer has inspected outcomes, examples, and assessments;
- [ ] a representative learner has completed the first-mile setup;
- [ ] assignment creation, submission, feedback, and grade recording have been
      proven end to end;
- [ ] accessibility and device friction have been reviewed;
- [ ] the external course URL and recovery procedures have been verified;
- [ ] all private cohort data remains outside this repository.
