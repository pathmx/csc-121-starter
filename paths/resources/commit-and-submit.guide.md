# Save and submit your work

## Foundations: Thonny and the LMS

1. In Thonny, choose **File → Save**.
2. Confirm the file has the exact required name, such as `me.py`.
3. Press **F5** and complete the required checks.
4. Close and reopen the file if you are unsure where it was saved.
5. Upload the saved `.py` file through the course's stated LMS assignment.
6. Reopen the uploaded file or submission receipt and confirm it is the version
   you intended to submit.

Do not rename a file by adding `.txt`, submit a screenshot instead of code, or
upload a shortcut to a file that remains only on your computer.

## Applied and final projects: GitHub

A commit records a meaningful project checkpoint. A push copies committed
checkpoints to GitHub. The instructor will teach this workflow before it is
required.

### Command-line workflow

```sh
git status
git add main.py
git commit -m "Add profile card variables"
git push
```

Use a message that describes what now works. “Update” or “stuff” will not help
you understand the history later.

### Before you call a repository submitted

- [ ] Run the program one final time.
- [ ] Use `git status` and understand every listed file.
- [ ] Commit the intended work.
- [ ] Push successfully.
- [ ] Open the repository on GitHub.
- [ ] Confirm the latest commit and code are visible there.

Do not commit `.env`, API keys, passwords, private data, or a virtual
environment.
