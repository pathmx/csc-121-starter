# Run a Python program in Thonny

1. Install Thonny from the [official website](https://thonny.org/) using the
   instructions for your operating system.
2. Open Thonny.
3. Choose **File → Open** and select the assigned `.py` file, or choose
   **File → New** and save it immediately with the required filename.
4. Press the green **Run current script** button or press **F5**.
5. Read the result in the **Shell** below the editor.

If Thonny asks where to save an untitled file, stop and confirm the required
folder and filename. If it runs the wrong program, check the active editor tab
before changing code.

Run a starter once before editing it. That separates environment problems from
problems introduced by a later change.
