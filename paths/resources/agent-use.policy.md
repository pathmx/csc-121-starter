# Responsible use of coding agents

A coding agent can inspect and edit a repository. That makes it more useful—and
more consequential—than a chat window that only sees pasted code.

## Before using one

- Check the permission for the current unit and assignment.
- Commit or otherwise preserve your working state.
- Remove secrets and private information from the repository.
- State the problem, relevant evidence, and what kind of help is allowed.

## Good bounded requests

- “Explain this traceback and ask me one question at a time.”
- “Review my plan for missing cases without writing the solution.”
- “Help me create a test for behavior I already implemented.”
- “Show me where the README no longer matches the program.”
- “For this final project, scaffold the Flask view while leaving
  `calculate_score()` for me.”

## Student responsibility

Before submitting agent-assisted work, you must be able to:

- identify what the agent changed;
- run and test it;
- explain important lines and design choices;
- revise it without asking the agent to regenerate everything;
- record material assistance in the form required by the instructor.

## What an agent should not decide

An agent does not own your learning goal, project scope, grade, academic
integrity judgment, or final claim that the work is correct. Your instructor
has final authority over course and assessment decisions.
