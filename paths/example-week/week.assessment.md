# Self-check: predict and explain

Complete this without running the code first. The goal is to notice what you
can reason through on your own.

---

## Predict

What exact output will this program produce?

```python
item = "notebook"
quantity = 3

print("Item:")
print(item)
print("Quantity:")
print(quantity)
```

Write your prediction on paper. Then run the code and compare.

---

## Explain

In one or two sentences each:

1. What does `print()` do?
2. What is the difference between `quantity` and `3`?
3. Why is `"notebook"` inside quotation marks?
4. Which one line could change the displayed quantity everywhere it is used?

---

## Transfer

Without copying the example, write a four-line program that stores a color and
then prints a label followed by that color.

If you cannot yet predict or explain the result, return to the
[lesson](./01-output-values-variables.lesson.md) and try one smaller example.
That is useful feedback, not failure.
