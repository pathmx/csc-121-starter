# Assignment: make a profile card

Create a small Python program that displays a fictional profile card. This is
an individual first-week assignment: type the code yourself and use only the
tools your instructor has approved.

You may begin with `starter-files/example-week/profile-card.py` if your
instructor provides the Starter files, or create a new file named
`profile-card.py`.

---

## Required behavior

Your program must:

- store at least four values in clearly named variables;
- include both text and a number;
- print a clear label before each value;
- use fictional or non-sensitive demonstration information; and
- run from beginning to end without an error.

The exact design is yours. A result might describe a fictional game character,
club member, or museum exhibit.

---

## Work in small steps

1. Sketch the output on paper.
2. Create one variable and print it.
3. Run the program.
4. Add one field at a time, running after each change.
5. Read the final output as if you were its user.
6. Add a short comment at the top naming the program's purpose.

---

## Evidence to submit

Submit the `.py` file in the place your instructor specifies. Be prepared to
run it and explain:

- what one variable name means;
- the difference between its name and its value; and
- which line you would change to update one field.
