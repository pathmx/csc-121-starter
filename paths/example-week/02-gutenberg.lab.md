# Lab: a tiny printing workshop

In this lab you will practice turning a short description into Python output.
Use Thonny and type the code yourself. The physical act of writing and revising
the program is part of the practice.

If your instructor provided the Starter files, open
`starter-files/example-week/lab.py`. Otherwise create a new file named
`lab.py`.

---

## 1. Confirm the file runs

Run the starter once. Read the output and locate the line that produced it.

If the program does not run:

1. read the final error line;
2. check quotation marks and parentheses;
3. compare your code one character at a time; and
4. ask for help with the exact error still visible.

---

## 2. Print a small notice

Create variables for a fictional event name, room, and start time. Print a
notice with a label and value on separate lines.

One possible result is:

```text
Event:
Python Practice
Room:
Lab 3
Starts:
2:00 PM
```

Run the program after each small addition.

---

## 3. Make one controlled change

Change only the room value and run the program again. Explain why the output
changed even though the `print()` instructions did not.

---

## Finish

Before leaving the lab, make sure the file runs from beginning to end and that
you can identify every stored value and every output instruction.
