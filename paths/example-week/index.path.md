# Example week: your first Python program

This sample week shows one possible rhythm for an introductory programming
course. Your instructor may replace it, shorten it, or teach it differently.

## By the end

You will be able to write and run a small Python program that uses output,
literal values, and variables. You will show that by creating a static profile
card and explaining what each line contributes.

---

## Sequence

1. [Lesson: output, values, and variables](./01-output-values-variables.lesson.md)
2. [Lab: a tiny printing workshop](./02-gutenberg.lab.md)
3. [Assignment: make a profile card](./03-profile-card.project.md)
4. [Self-check: predict and explain](./week.assessment.md)

The lesson and lab are supported practice. Complete the assignment more
independently, then use the self-check to decide what still needs practice.

When you finish, return to the [course home](../index.path.md).
