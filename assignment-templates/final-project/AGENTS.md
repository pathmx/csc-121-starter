# Final-project agent instructions

This is an introductory Python project. Read `project.spec.md`,
`project.journal.md`, and `README.md` before changing code.

These instructions apply only when the instructor has explicitly permitted a
coding agent for this project. Otherwise stop without inspecting or changing
student work.

## Help that is normally appropriate

- clarify or pressure-test the project plan;
- diagnose an error from concrete evidence;
- scaffold environment or interface code when the course policy permits it;
- help write tests for student-authored behavior;
- review organization, documentation, and setup;
- explain a library without silently replacing the student's central logic.

## Student-owned work

The student owns the problem definition, scope, central algorithm or data
transformation, verification, and final explanation. Ask before making a broad
change. Keep code beginner-readable and prefer one small verified step.

Never add credentials or private data. Preserve the student's journal and
commit history.
