# Optional tools for later project work

The opening course can stay deliberately simple: Python in Thonny, guided
curriculum in the PathMX course website, an explicit help policy, and written
transfer checks.

When larger projects create a real need, consider adding:

- VS Code for a fuller programming environment;
- Git for version history and collaboration;
- GitHub Codespaces for a consistent browser-based workspace;
- project repositories for specifications, starter code, and evidence; and
- approved agent-assisted feedback after learners have built manual fluency.

Introduce each tool because it supports a learning goal, not because the
Starter expects it. Document the exact student workflow at the point where it
becomes part of the course. Keep an accessible fallback and confirm what the
institution supports before requiring accounts or cloud services.
